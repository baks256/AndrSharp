# AndrSharp

Короткий практический курс C# для ребёнка примерно 10 лет.

Цель — понимать C#, а не повторять код под диктовку. Сквозной проект — консольные «Танчики». Сеть появится позже, после уверенной базы языка.

## Как проходит урок

Каждая папка — один короткий урок.

1. Прочитай `README.md` урока.
2. Пройди короткий тест по теории, если он есть.
3. Напиши код сам.
4. Запусти проверку.
5. Все проверки зелёные — урок пройден.

## Первый запуск

Установи:

- .NET 10 SDK;
- Visual Studio Code;
- рекомендуемые расширения, которые предложит VS Code.

Клонируй репозиторий и **открой в VS Code корень папки AndrSharp**, а не отдельный файл или папку урока.

Начни с [00-setup](00-setup/README.md).

## VS Code уже настроен

Настройки хранятся прямо в репозитории.

- `Ctrl+S` — сохранить и автоматически отформатировать C#.
- `F5` — запустить открытый урок.
- `Ctrl+Shift+B` — проверить открытый урок.
- `Shift+Alt+F` — форматировать вручную.

Если автоформатирование не работает, не начинай первый урок: сначала пройди `00-setup`.

## Что будем изучать

Сначала фундамент: переменные и типы, константы, выражения, `bool`, сравнения, `if/else`, циклы, методы, параметры, `return`, область видимости, классы и объекты, поля, `public/private`, свойства и конструкторы.

Наследование — позже. Сеть — ещё позже.

## Как проверяется код

В простых консольных заданиях тесты работают как **input → output**: запускают программу, передают вход и сравнивают результат с ожидаемым.

Когда появятся методы и классы, тесты будут проверять их напрямую: результаты методов, состояние объектов и структуру класса.

## Родителю

Не диктуем программу построчно. Сначала вопросы и подсказки: что надо сохранить, что проверить, что повторить, какой метод нужен. Готовый код — последняя подсказка.

Главная проверка понимания: ребёнок способен с чистого файла написать маленькую программу и объяснить каждую строку.
