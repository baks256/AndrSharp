# Урок 00. Проверяем компьютер

Здесь пока не учим C#. Наша задача — убедиться, что всё готово.

## 1. Запусти программу

Открой `Program.cs` и нажми `F5`.

Должно появиться:

```text
Привет! Всё работает.
```

## 2. Проверь автоформатирование

В `Program.cs` специально испорть пробелы или скобки и нажми `Ctrl+S`.

VS Code должен сам привести код в порядок.

## 3. Запусти проверку

Оставь `Program.cs` так, чтобы он печатал ровно:

```text
Привет! Всё работает.
```

Нажми `Ctrl+Shift+B`.

Если увидишь зелёную галочку — компьютер готов к занятиям.
